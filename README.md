# ctf-2025-badge
Badge related files for CTC 2025 CTF

<img width="559" height="400" alt="badge2025" src="https://github.com/user-attachments/assets/077bf8fb-5492-40a6-8438-e4774fa6e0d4" />

## Info

- ESP32-C3-Mini
- Micropython
- E-ink display (GDEW0154M10) with UC8151 custom driver for quick partial refreshes
- IO expander (XL9535)
- EEPROM
- SAO

See schematics: [ctc_2025.pdf](hardware/ctc_2025.pdf)
